# JARVIS — Complete Voice Interaction Setup

JARVIS features a bidirectional voice intelligence pipeline with real-time speech synthesis, microphone controls, and Bangla/English language auto-detection.

## Features
- **Speech-to-Text (STT)**: Real-time browser Web Speech API & optional Gemini transcription.
- **Text-to-Speech (TTS)**: Multi-voice synthesis (`bn-BD` and `en-US`).
- **Push-to-Talk & Continuous Mode**: Speak naturally to JARVIS.
- **Barge-In Support**: Interrupting audio playback immediately stops speech synthesis and returns JARVIS to listener state.

## Microphone Permission Fix for Windows
If microphone access is blocked:
1. Open Windows Settings -> Privacy & Security -> Microphone.
2. Enable "Allow apps to access your microphone".
3. Enable "Allow desktop apps to access your microphone".
