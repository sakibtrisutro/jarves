# JARVIS Release Notes & Changelog

## Version 3.0.0 (Master Release)
- **Model Control Center**: Zero-Configuration First Boot, Independent API Key Manager (Gemini, OpenAI, OpenRouter), Instant Free Model Bootstrap, and Force Model Mode.
- **Voice Intelligence**: Full bidirectional voice interaction with Bangla (বাংলা) and English auto-routing and Barge-In audio suppression.
- **Multi-User Auth**: Multi-account login (Sakib & Sanjida) with personalized memory and voice personas.
- **Windows Deployment**: Complete set of 9 root batch scripts (`install.bat`, `start.bat`, `stop.bat`, `restart.bat`, `update.bat`, `diagnostics.bat`, `backup.bat`, `restore.bat`, `uninstall.bat`).
- **SQLite WAL Storage**: ACID-compliant persistent operational database engine.
